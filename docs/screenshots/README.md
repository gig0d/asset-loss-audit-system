# Capturas pendientes

Las siguientes capturas visuales están pendientes de obtener desde una sesión real del dashboard:

1. Resumen completo después de cargar la demostración.
2. Alertas filtradas por proveedor y regla.
3. Historial de seis rechazos de la muestra.

Ejecutar `streamlit run app.py`, pulsar **Cargar demostración** y guardar aquí las capturas correspondientes. No se incluyen imágenes simuladas ni se presentan maquetas como capturas reales. Las pruebas de interfaz automatizadas se documentan por separado en el README principal.
